# Cline compatibility
- This project is also used with Cline. Its setup is the reference.
- At the start of each task, read memory-bank/ and the files in .clinerules/ (skip hooks/ and workflows/).
- Skills live in .cline/skills/<name>/SKILL.md. When a task matches a skill's description, read that SKILL.md and follow it.
- Treat .clinerules/workflows/*.md as step-by-step checklists. Follow one only when I name it.
