# Style Rules

## Do not use mdashes

Never use the mdash character ("--") in any written output -- commit messages,
code comments, user-facing text, cline rules, memory-bank files, or chat
replies. Use a hyphen (-) or rephrase the sentence instead.

Mdashes are a common AI tell and make writing look generated rather than
human. If you need a break in a sentence, use a hyphen, a colon, a
semicolon, or split it into two sentences.
